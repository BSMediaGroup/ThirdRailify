# Illustration sources

`mountain-goat-cc0.svg` is the public-domain mountain-goat line drawing uploaded by papapishu to Openclipart. The source identifies the artwork as a Pearson Scott Foresman illustration donated to Wikimedia Commons and released into the public domain.

- Source: https://openclipart.org/detail/121051/mountain-goat
- Download: https://openclipart.org/download/121051
- License: Public domain / CC0-compatible unrestricted reuse

The GOATS hero uses the SVG as a CSS mask so its colour and opacity remain controlled by the site theme.
