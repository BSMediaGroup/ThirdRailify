# Third Railify data-retention matrix

Internal engineering inventory as at 28 August 2026. A technical expiry or capacity bound is recorded only where source implements it. `NO FIXED APPLICATION RETENTION POLICY CONFIRMED` means owner and qualified legal review must decide the policy; it is not permission to retain forever or delete immediately.

| Domain / record | Storage authority | Implemented retention or capacity | Cleanup mechanism | Automatic / manual | Remaining decision |
| --- | --- | --- | --- | --- | --- |
| Auth sessions | Admin auth D1 `sessions` | 8 hours | Master-only expired-auth cleanup deletes `expires_at <= operation time`; runtime rejects expired/revoked rows | Manual, bounded | Confirm maintenance cadence and any audit/preservation need |
| Login handoffs | Admin auth D1 `auth_handoffs` | 5 minutes | Same expired-auth cleanup | Manual, bounded | Confirm cadence |
| OAuth transactions | Admin auth D1 `oauth_transactions` | 10 minutes | Same expired-auth cleanup | Manual, bounded | Confirm cadence |
| Email verification tokens | Admin auth D1 `email_verification_tokens` | 24 hours | Same expired-auth cleanup | Manual, bounded | Confirm cadence |
| Password reset tokens | Admin auth D1 `password_reset_tokens` | 30 minutes | Same expired-auth cleanup | Manual, bounded | Confirm cadence |
| Provider identities | Admin auth D1 `auth_identities` | NO FIXED APPLICATION RETENTION POLICY CONFIRMED | Cascades only if an account row is deleted; no account deletion workflow exists | None | Owner/legal retention and unlink/deletion policy |
| Password credentials | Admin auth D1 `password_credentials` | NO FIXED APPLICATION RETENTION POLICY CONFIRMED | Replaced on password reset; cascades only with account deletion | Event-driven replacement; no general cleanup | Owner/legal account lifecycle policy |
| Account records/profile URLs | Admin auth D1 `accounts`; profile bytes in Admin R2 | NO FIXED APPLICATION RETENTION POLICY CONFIRMED | Disable/revoke and avatar replacement exist; no account delete | Manual partial controls | Owner/legal account closure and R2 deletion policy |
| Auth rate-limit state | Admin auth D1 `auth_rate_limits` | Operational windows vary by category from 15 minutes to 24 hours; NO FIXED APPLICATION RETENTION POLICY CONFIRMED for old rows | Same hashed key/category is overwritten; no stale-row purge | Automatic overwrite per key; no purge | Approve stale-row cleanup rule without weakening abuse controls |
| Auth audit/events | Admin auth D1 `auth_audit` | NO FIXED APPLICATION RETENTION POLICY CONFIRMED | None | None | Security, dispute, privacy and legal retention decision |
| Turnstile-derived data | Turnstile receives token/IP context; Admin retains no raw Turnstile response table | No application record beyond request processing; provider retention not verified | Request-scoped processing | Automatic in application | Provider contract/privacy review |
| GOATS draft submissions/uploads | Admin Commerce D1 `community_submissions`; Admin GOATS R2 | 24 hours while unfinalised | Master-only cleanup selects only expired drafts, deletes their R2 objects, then guarded draft rows | Manual, bounded | Confirm operator cadence; legal review procedure |
| GOATS approved/final submissions and media | Admin Commerce D1/R2; bounded approved projection to Public | NO FIXED APPLICATION RETENTION POLICY CONFIRMED | Hide/restore and media editing; no non-demo permanent delete | Manual partial controls | Owner/legal publication, deletion, backup and consent-evidence schedule |

| GOATS reactions | Admin Commerce D1 `community_reactions` | NO FIXED APPLICATION RETENTION POLICY CONFIRMED | Signed-in user can remove own reaction; Admin moderation state | Manual/event-driven | Decide residual moderation/audit treatment |
| GOATS moderation events | Admin Commerce D1 `community_moderation_events` | NO FIXED APPLICATION RETENTION POLICY CONFIRMED | None; cascades if submission is lawfully deleted | None | Owner/legal evidence schedule |
| GOATS transactional outbox/delivery metadata | Admin Commerce D1 `community_email_outbox` | NO FIXED APPLICATION RETENTION POLICY CONFIRMED; retry capped at 20 attempts | Retry updates same row; no purge | Manual retry; no purge | Delivery-evidence, recipient and failure-record schedule |
| GOATS email templates | Admin Commerce D1 `community_email_templates` | Current revision retained; NO FIXED APPLICATION RETENTION POLICY CONFIRMED | Admin update replaces current row | Manual update | Decide historical template evidence requirements |
| GOATS rate-limit state | Admin Commerce D1 `community_rate_limits` | Operational windows are encoded per category; NO FIXED APPLICATION RETENTION POLICY CONFIRMED for old rows | Same hashed key/category is overwritten; no stale-row purge | Automatic overwrite per key; no purge | Approve stale-row cleanup rule |
| Wheels and participant entries | Admin Commerce D1 `wheels`, `wheel_entries`, `wheel_access`, `wheel_creator_grants` | NO FIXED APPLICATION RETENTION POLICY CONFIRMED | Owner/editor archive retains the wheel; Master may hard-delete only a wheel with zero official results | Manual lifecycle and restricted deletion | Owner/legal publication, account-link, backup and deletion schedule |
| Official wheel results/audit | Admin Commerce D1 `wheel_official_spins`, `wheel_audit_events` | Immutable application evidence; NO FIXED APPLICATION RETENTION POLICY CONFIRMED | Master void annotates and preserves the result; no ordinary hard delete | Append-only/manual void | Security, giveaway/dispute, privacy and legal evidence schedule |
| Wheel rate-limit state | Admin Commerce D1 `wheel_rate_limits` | Operational windows vary by mutation; NO FIXED APPLICATION RETENTION POLICY CONFIRMED for old rows | Same hashed key/category is overwritten; no stale-row purge | Automatic overwrite per key; no purge | Approve stale-row cleanup without weakening abuse controls |

| Stripe webhook records | Admin Commerce D1 `commerce_webhook_events` | NO FIXED APPLICATION RETENTION POLICY CONFIRMED | Duplicate-safe insert/update; no purge | Automatic ingest; no cleanup | Security/payment evidence schedule |
| Fulfilment/Printful identifiers and mappings | Admin Commerce D1 | NO FIXED APPLICATION RETENTION POLICY CONFIRMED | No order submission or fulfilment mutation; migration leases expire operationally | Lease expiry is automatic eligibility; no record purge | Owner/legal/provider schedule |
| Refund records | Amount/status columns and draft template exist; no operational refund table/action | NO FIXED APPLICATION RETENTION POLICY CONFIRMED | No refund mutation | None | Define authority, schema and retention before activation |
| Commerce audit, profiles, tax, permissions, templates/settings | Admin Commerce D1 | NO FIXED APPLICATION RETENTION POLICY CONFIRMED | Current-row updates/revocations; audit is append-only | Manual/event-driven | Legal/business/security schedule |
| Transactional account email | Resend delivery request; application has no account-email outbox table | No application delivery record beyond auth/audit flow; provider retention not verified | None in application | Provider-managed | Provider contract and evidence policy |
| Public contact enquiry | Resend delivery request to configured Third Railify inbox and CC; no application contact table/outbox | No application copy after delivery request; mailbox and Resend retention are provider/operator-managed and not verified | None in application | Provider/mailbox-managed | Owner retention and provider contract review |
| Watch current state | Public SQLite Durable Object `snapshots` row `broadcast` | One current normalized snapshot, overwritten on semantic change or checkpoint | Upsert replaces the row | Automatic | No additional application retention rule required; provider/source retention remains external |
| Watch archive | Public SQLite Durable Object row `broadcast_archive` | Exact cap of 24 eligible programme records | A 25th eligible record deterministically prunes the oldest within the rewritten archive | Automatic | Owner/editorial policy for manual visibility and external source records |
| Community current state | Public SQLite Durable Object row `community` | One current normalized public snapshot | Upsert replaces the row | Automatic | External Discord/source retention remains provider-controlled |
| Consent preference | Host-only `thirdrailify_consent` cookie | 183 days; schema version 1 | Expiry/browser clearing; later choice replaces it | Automatic expiry/manual choice | Reassess only if purposes/categories change |
| Currency preference and cached rates | Public device optional keys | NO FIXED TIME; until withdrawal, replacement or clearing | Withdrawal removes both; replacement on choice/fetch | Automatic replacement/manual withdrawal | None beyond accurate notice |
| GOATS browser draft preference | Public device optional key | Until submission, withdrawal or clearing | Removed on successful submission or Preferences withdrawal | Event-driven/manual | None beyond accurate notice |

Backups, provider-side records, support correspondence and legal holds are not represented by a fixed application policy. Their periods and exceptions require owner decision, provider confirmation and qualified legal review.
